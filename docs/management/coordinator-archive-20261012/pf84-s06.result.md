- **Slice A:** an account stores only the profile name, validated and shown in clear. It works through `corbanu account add/list/rename/remove` (rename is new) and `/providers`, and `/status` names the account.
  - Requests are signed by that profile only. Environment keys, `AWS_PROFILE`, the bearer token, the managed key, and `credential_source` pointing at the environment, EC2 instance or ECS container are all ignored or refused.
  - A missing or broken profile is refused with the reason before any request, and nothing falls back. SSO profiles are allowed.
- **Slice B:** each account keeps its own sign-in in the vault, and refreshed tokens are saved back to that account only.
  - New commands: `corbanu login --account <name>` (browser, device code, `--with-api-key`), `login --account <name> status` and `logout --account <name>`. `/providers` can add an account by device code or a masked API key.
  - The default login is never read or changed (the `auth.json` hash was identical before and after every run).
  - Rows show only the kind, an email hint, the plan and a fingerprint. Signing the same ChatGPT user in twice gives a warning, not a refusal.
  - `forced_login_method` and the forced-workspace setting apply to named accounts too.

**Still open**
- **Code-blind acceptance:** S06 is ready for an independent run; I did not run it.
- **Issue #548 (existed before this work, also affects the default account):** the AWS SDK's own logging can write a credential helper's error output into Corbanu's logs. Error messages shown to the user already cut it out.
- **Known limit (documented in the gate):** after switching mid-session from a named OpenAI account to the default account, model requests use the default, but connectors and accounting stay on the named account. The model list also comes from the account the process started on.
- **CI:** a Windows sandbox test unrelated to these changes failed once on #543 and passed on rerun; it has failed once on main before.
- **Cleanup:** worktrees, local branches, the build folders on the Mac and glitch, and scratch homes are removed. The Mac build folder was reused from slice A to slice B after slice A was finished.
