normal-library mutation accepting bounded original numeric evidence for unseen
attempts whose detail has expired but whose replay horizon has not.
It atomically writes owner/day compact totals, referenced original snapshots and
anonymous UUID/expiry tombstones. Include normal-crate native-owner read/delete,
idempotency, rollback, concurrency and restart proof in the same candidate.
No aged raw SQL staging, schema, collector, automatic scanner, new price authority
or independently callable partial transfer. Keep admit/observe and their aged
raw rejection unchanged: the existing negative tests remain valid.

The first supported source shape is a complete immutable evidence snapshot
(including an interrupted attempt with unknown fields), not incremental updates
to an already compacted attempt. “Complete” describes the submitting embedding's
contract; the store cannot prove missing source records do not exist. No boolean
claim such as authenticated=true/final=true substitutes for provenance.

## Precise invariants and outcomes

- Proposed bounds:1..64 entries for one native owner, <=256 observations each,
  <=4096 observations per bundle, enforced before cloning/sorting. Reuse bounded
  Attempt metadata. Typed OriginalPriceEvidence::Bound(Snapshot)/Unpriced, not
  arbitrary candidates. DTOs are in-memory, not a new persisted wire protocol.
- Checked time: dispatch+90d <= as_of < dispatch+365d; nonnegative and no backward
  checkpoint/future dispatch/overflow. Independently apply UTC-day-start+365d.
  No clamping time or shortening replay to90d.
- Native owner equals every attempt.thread_id and exists under the writer lock.
  Never upsert owners, mint replacement IDs/times, alter spawn edges or create an
  authorization registry. Parent and child imports remain independently owned.
- Unseen attempts may have a complete retry chain in the same bounded bundle;
  topologically validate same_owner predecessors and cycles. A retained raw
  predecessor may prove an edge; an opaque tombstone cannot. Reject unsupported
  erased external ancestry instead of treating supplied text as retained proof.
- Normalize identical duplicate revisions once; reject conflicting revisions,
  attempt identities, request-owner collisions and source/sequence reuse within
  input and against retained raw evidence. Validate every replay prefix.
  No cross-erased-source authenticity claim is possible with anonymous dedup.
- Tombstone hits never add, update, reprice or extend expiry. Report
  SuppressedByReplayRecord, NOT “identical payload.” Erased bytes cannot establish
  equality. All-seen repetition needs no reconstructed retry graph.
  Validate bounds/native owner/basic identity/time first; malformed/expired input
  can still reject. No duplicate result discloses the tombstone's previous owner.
- Existing raw identity colliding with import is rejected, never overwritten;
  existing raw/NULL bindings remain authoritative and maintenance handles them.
  Changing old compacted usage or filling its old missing price is not supported.
- Bound snapshot must be valid, dispatch-eligible and exactly the selected
  original descriptor. Reject an ineligible Bound input instead of silently
  converting it to unpriced; reject same-ID unequal stored bytes. No backdating,
  present-catalog projection, alternate unused snapshot insertion or approval
  inference. Absent trustworthy price evidence means explicit Unpriced.
- Preserve omitted/null/zero, known subtotal versus unknown estimates, seven
  measured populations, cache subsets, reasoning subset and exact24-place USD.
  Validate the resulting raw+compact day, not just individually valid additions.
- Outcome per input: Imported, SuppressedByReplayRecord or ExpiredAggregateDay.
  Expired day with remaining rolling replay lifetime writes only its anonymous
  tombstone; it cannot recreate the day or retain an unreferenced price.
- No request/observation/source-position/price-binding/per-attempt amount/hash
  ledger may survive as disguised detail. Five raw tables receive no import
  INSERT, even transiently. Input is not copied to SQLite TEMP tables or logs.
- Deleted existing IDs stay fenced through replay expiry; missing native owner
  rejects. Native deletion of imported compact ownership preserves other owners'
  snapshots and removes attributable totals. Native upsert can recreate an ID:
  unseen attempts for a recreated owner are not permanently fenced here.
  After tombstone expiry, original old dispatch still rejects by time; a forged
  new UUID/dispatch is outside what anonymous expired storage can authenticate.

## Single transaction and cancellation

Facade owns BEGIN IMMEDIATE and one commit/rollback, with explicit as_of.
Validate installed ledger/schema/Active state and durable monotonic checkpoint;
never install or activate implicitly through the import method. Inspect raw and
tombstone collisions before maintenance can erase their authority. Validate and
normalize input in memory, building checked quotes and proposed additions.
All-suppressed valid input may return without mutation/maintenance; document that
it does not advance coverage to a later requested as_of.

For unseen input, run existing complete maintenance at as_of within this same
transaction; merge exact additions into surviving compact days; insert only
selected immutable snapshots, union references and exact-expiry tombstones.
Apply conservative expired-day outcome, GC as necessary, then validate full
resultant retained state and all raw+compact sums. Any failure, including a
maintenance failure or commit-time FK failure, rolls back this entire operation.
Readers see old or new complete state. Public deletion serializes at the same
main-state writer lock; logs/memory/goals remain separately transactional.
Cancellation may commit before its acknowledgement is lost: re-open and retry
the original IDs, never mint replacement IDs or claim dropping a SQL future
guarantees rollback. No physical WAL erasure or power-loss/fsync claim.
