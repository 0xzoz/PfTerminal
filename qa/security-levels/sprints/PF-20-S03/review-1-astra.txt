[P2] [P2] Bound connection establishment before starting the handshake
codex-rs/protected-state/src/native.rs:305
`UnixStream::connect` runs before any timeout is configured. If the root listener's backlog fills and it stops accepting connections, this call can block indefinitely; the ten-second frame deadlines never start. Linux explicitly waits for queue space during blocking Unix-stream connection establishment ([kernel implementation](https://raw.githubusercontent.com/torvalds/linux/master/net/unix/af_unix.c)). This leaves the production bootstrap outside the required bounded transport behavior. Create and configure the socket before connecting, using a bounded connection deadline or nonblocking failure, while preserving the existing no-reconnect semantics.
