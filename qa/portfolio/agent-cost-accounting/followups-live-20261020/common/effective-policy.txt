acc-tart1 changes:
- api.openai.com also forwards `/v1/realtime`, WebSocket upgrades only (a plain request gets 403); realtime sessions
  are capped for the whole run (REALTIME_CAP=2: one session plus one spare for a harness failure); over the cap the
  relay refuses with 403. The usage object of every realtime `response.done` server event is logged
  ("realtime_response_done"); no other frame content is logged.
- Moonshot POSTs capped at MOONSHOT_CAP=4 (owner decision D54, option a, 2026-10-20 ~01:57Z), replacing S10's 12.
- Upstream connections to api.openai.com go to its pinned address (--pin api.openai.com=162.159.140.245).
- A missing key file is not loaded (that host answers 503); not needed in the real run (all three keys were placed).
- A direct TLS listener for clients that ignore HTTPS_PROXY exists (--realtime-port) but was NOT enabled in the real
  run: the shakedown showed the product's realtime client goes through the proxy.
