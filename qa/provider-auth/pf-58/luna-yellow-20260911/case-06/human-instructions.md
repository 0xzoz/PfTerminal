# 6. Switch models and compare both labels

Use /model to select a different provider/model, then switch back to Fable 5.1 Max. Watch the boxed model indicator near the top and the footer throughout.

Pass: both labels update immediately after each selection and always agree—no redraw, restart, or prompt is required.

Fail: the footer changes while the boxed indicator remains on the previous model, or either label changes before selection is complete.
