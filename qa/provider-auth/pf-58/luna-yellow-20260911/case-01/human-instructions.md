# 1. Launch from the app shortcut

Open a new window using Corbanu Terminal Launcher in Applications. Existing windows keep their older running binary; use the app shortcut—not a shell command or debug launcher—to test the new Mac package.

Pass: a new Terminal window opens on Desktop 3 in the first free position of the 2 × 3 card grid.

Fail: it opens beside Codex on another desktop, overlaps an existing terminal, says the build is missing, or opens a debug build.
