# 3. Inspect the unified provider catalog

Run /providers. Move through the list, inspecting OpenAI, Anthropic/Claude, Corbanu API, API-key providers, and any local/custom entries. Then run /wallet and inspect the Corbanu API entry.

In /model, select Ambient: its only offered model should be GLM 5.2. Kimi 2.7 should not appear under Ambient; other providers' Kimi models are unchanged.

Pass: the lists open promptly; configured, active, current, unavailable, and recovery states make sense; the wallet offers dollar balance, top-up, model prices, and API-key management without Starter/Basic/Power/Pro plan-sale actions.

Fail: statuses contradict startup, secrets are visible, key navigation pauses repeatedly, the vault hangs, Corbanu API is absent, or a legacy Corbanu Plan purchase/recovery/details action is visible.
